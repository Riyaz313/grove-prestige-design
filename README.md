## 4. WEBSITE STRUCTURE

Build a complete, polished single-page website with working navigation and these sections:

### A. Premium Header

* Project branding using a supplied logo if available.
* Navigation: Overview, Residences, Amenities, Floor Plans, Location, Offers, Contact.
* Sticky header with subtle styling changes on scroll.
* Prominent gold-accented Enquire Now button.
* Functional mobile hamburger menu.

### B. Cinematic Hero

* Use the best available original project exterior or architectural image.
* Large elegant headline: “A New Perspective on Elevated Living.”
* Identify Prestige Golden Grove and its Tellapur, Hyderabad location.
* Short, sophisticated description based on the brochure.
* Primary CTA: Explore Residences.
* Secondary CTA: Request Information.
* Include only verified project statistics.

Make this section visually striking and establish the premium brand identity immediately.

### C. Project Overview

* Present verified project scale, towers, location, and other brochure-supported facts.
* Use an editorial composition with large typography, original images, and elegantly designed statistics.
* Keep text concise and avoid unnecessary paragraphs.

### D. Project Gallery

* Build a responsive, premium image gallery using supplied visuals.
* Include architectural imagery, residences, landscaping, and amenities when available.
* Add a simple image enlargement/lightbox interaction.
* Never present unrelated stock images as actual project photographs.

### E. Residences and Configurations

Display the six residence collections listed in the brochure:

* 2 BED Classic
* 3 BED Aspire
* 3 BED Premia
* 3 BED Ultima
* 4 BED Supreme
* 4 BED Ultima

Show the correct configuration, bedroom/bathroom count, size, and relevant details only when confirmed by the brochure.

Use a visually sophisticated layout with selective image-led cards, concise descriptions, and View Floor Plan buttons.

### F. Floor Plan Explorer

* Include all 27 original layouts if the uploaded files provide them.
* Organize them by residence collection and configuration.
* Add simple working category filters.
* Show the original floor-plan image, its official label, and verified measurements.
* Allow users to enlarge each plan.
* Preserve image proportions and make labels readable.
* Never redraw a plan inaccurately or invent missing dimensions.
* Reuse supplied images instead of creating 27 replacement graphics.

### G. Amenities

Create a premium editorial amenities section with large original images and grouped categories, such as fitness, sports, indoor recreation, leisure, and landscaping, where supported by the brochure.

Include only amenities explicitly shown or described in the supplied materials. Use asymmetric image layouts and restrained text instead of a wall of generic icons.

### H. Master Plan

Display the original master plan prominently, with an enlarge/view option and a concise explanation based on the brochure.

### I. Location and Connectivity

* Show the project location as described in the brochure.
* Present nearby destinations and advertised travel times in a clean visual layout.
* Clearly label journey times as estimates that vary with traffic.
* Do not invent distances, transport connections, or nearby facilities.
* Do not integrate a paid map API.

### J. Specifications

Organize verified brochure specifications into clear categories, including structure, flooring, kitchen, bathrooms, doors and windows, electrical provisions, security, and backup power where applicable.

Use a refined accordion or compact editorial layout to maintain readability.

### K. Pre-EMI Promotional Offer

Use the supplied promotional image and create a premium offer section with a visual payment timeline.

Present the advertised payment structure only after checking the supplied image. Explain that lender eligibility, loan sanction, dates, offer validity, and contractual terms must be confirmed with the developer and relevant lender.

Clearly distinguish promotional claims from verified contractual terms. Do not guarantee loan approval, savings, or payment benefits.

### L. Price Estimator

Build a lightweight working calculator with:

* Apartment area in square feet.
* Editable assumed price per square foot.
* Down-payment percentage.
* Estimated property value.
* Estimated down payment and remaining balance.

Label all figures as illustrative. Do not insert an invented official price. Use neutral initial values or ask the user to enter assumptions within the calculator.

### M. FAQ

Include concise answers covering residence configurations, floor plans, amenities, location, brochure requests, and the advertised offer.

Use brochure-supported information only. Mark details requiring confirmation instead of inventing answers.

### N. Enquiry Form

Build an attractive, accessible form with:

* Full name.
* Phone number.
* Email address.
* Preferred apartment configuration.
* Message.

Add input validation and a clear submission state. If no backend or form service exists, display an honest demo confirmation and explain that the enquiry has not been transmitted to a sales team. Do not simulate a real email or lead submission.

### O. Final CTA and Footer

Finish with an elegant, image-led enquiry banner, contact CTA, navigation links, project identity, and a concise information disclaimer.

Use contact details only when verified by the uploaded material or explicitly supplied by the project owner.
